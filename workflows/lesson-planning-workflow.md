# Lesson Planning Workflow

> **Workflow:** a repeatable sequence of steps an AI agent follows to turn an input into a finished deliverable.

## Objective
Produce a one-session Java lesson plan for intro programming students.

## Inputs
| Input | Example |
|---|---|
| Topic | Encapsulation in Java |
| Session length | 75 minutes |
| Prior knowledge | Classes, objects, fields |

## Steps
1. **Clarify** — confirm topic, length, and student level.
2. **Plan** — outline learning goals, key terms, and activities.
3. **Draft** — write the lesson with one runnable code example.
4. **Review** — check accuracy, timing, and terminology.
5. **Deliver** — save the final file to `/outputs`.

## Output
`/outputs/<topic>-lesson-plan.md`

## Quality Checklist
- [ ] Every term is defined before it is used
- [ ] Code example compiles and runs
- [ ] Activities fit the session length
