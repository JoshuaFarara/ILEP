# Outputs

Finished deliverables, organized **by type**. Each type gets one folder.

| Folder | Holds | File name pattern | Made by |
|---|---|---|---|
| `research/` | Cited research reports | `<topic>-research-report.md` | `/research` |
| `lesson-plans/` | Lesson plans and their app activities | `<topic>-lesson-plan.md`, `<topic>-activities.json` | `/lesson-plan` |

## Naming Rules
- Lowercase, hyphenated topic: `encapsulation`, `oop-mvc-javafx`.
- A lesson plan and its activities file share the same `<topic>` prefix and sit side by side.
- No spaces or special characters.

## Adding a New Output Type
1. Create the folder (for example, `outputs/quizzes/`).
2. Add a row to the table above.

Work in progress belongs in `/drafts`, not here.
